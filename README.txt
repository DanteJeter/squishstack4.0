UPLOAD
Upload the CONTENTS of this folder to your web server's public web directory.
The root index.html should be at https://www.squishstack.com/index.html
Keep the assets/ and games/ folder structure unchanged.

No database or build process is required. It is a static HTML/CSS/JavaScript package.

NOTE
The page imports Google Fonts when internet access is available. If blocked, it automatically falls back to system fonts.
